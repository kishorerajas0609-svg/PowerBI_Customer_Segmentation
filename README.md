# Power BI Customer Segmentation

This repository contains a customer segmentation analysis project built in Microsoft Power BI using an ecommerce customer dataset. The project includes a Power BI report file, the source dataset, and dashboard screenshots that illustrate the analysis output.

## Project Overview

The goal of this project is to segment customers based on behavioral and demographic patterns in an ecommerce dataset. The analysis can help identify:

- High-value customers
- Frequent buyers
- Inactive customers
- Customer groups by spending or engagement
- Opportunities for targeted marketing and retention strategies

This project is useful for business intelligence, analytics, and customer relationship management workflows.

## Repository Contents

- `customer_segmentation.pbix`  
  The Power BI desktop report containing the dashboard, visuals, and segmentation logic.

## Prerequisites

To open and use the project:

- Microsoft Power BI Desktop
- A compatible version of Windows for running Power BI Desktop
- The source CSV file included in this repository

## How to Use

1. Download or clone this repository.
2. Open `customer_segmentation.pbix` in Power BI Desktop.
3. If prompted, ensure the dataset path points to `ecommerce_customer_data.csv`.
4. Refresh the data if necessary.
5. Explore the visuals and segmentation metrics in the report.
